# Pamoki brand assets

All logos are vector SVG (text converted to shapes, so no font is needed) with PNG copies.
Direct link: `https://pamoki.com/assets/<file>`

## Logos

| File | Use it for |
|---|---|
| `pamoki-logo.svg` / `pamoki-logo-1200.png` | Main logo on light backgrounds |
| `pamoki-logo-white.svg` / `pamoki-logo-white-1200.png` | Logo on dark backgrounds |
| `pamoki-logo-stacked.svg` / `pamoki-logo-stacked-800.png` | Square spaces, posters, splash screens |
| `pamoki-logo-mono.svg` | One color (stamps, embroidery, small print) |
| `pamoki-wordmark.svg` / `pamoki-wordmark-1200.png` | Name only |
| `pamoki-mascot.svg` / `pamoki-mascot-512.png` | The mascot alone (stickers, loading screens) |

## Icons

| File | Use it for |
|---|---|
| `pamoki-app-icon.svg` / `pamoki-app-icon-1024.png` / `-512.png` | App icon with rounded corners |
| `pamoki-app-icon-square.svg` | App stores (they round the corners themselves) |
| `pamoki-avatar-400.png` | Profile picture: Instagram, TikTok, X, YouTube, GitHub |
| `favicon.svg`, `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` | Website icons |
| `og-image.png` | Link preview when pamoki.com is shared |

## Font

**Fredoka** (Google Fonts, free, SIL Open Font License). Wordmark: weight 600. Tagline: weight 500.

## Simple rules

- Leave space around the logo (at least the height of the sprout).
- Don't stretch, rotate or recolor the mascot.
- Use the white version on dark or busy backgrounds.
